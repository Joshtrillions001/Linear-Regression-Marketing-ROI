# Simple Linear Regression - Marketing ROI Analysis

## Project Description
This mini-project implements a Simple Linear Regression model to analyze a marketing spend dataset and evaluate the return on investment (ROI) across different advertising channels: TV, Radio, and Social Media. Through data cleaning, exploratory data analysis, and OLS regression modeling, we identify the single most impactful predictive channel to drive actionable business choices.

## Core Project Steps Completed
1. Loaded and cleaned the marketing dataset by handling missing values.
2. Performed Exploratory Data Analysis (EDA) with visual scatter plots to justify feature selection.
3. Fit a statistically valid Ordinary Least Squares (OLS) regression model using `statsmodels`.
4. Verified linear regression assumptions (Linearity, Homoscedasticity, Normality) using residual diagnostic plots.
5. Formulated an ROI-driven business recommendation for stakeholders.

## Environment Setup & Dependencies
To run this project locally, ensure you have Python installed, then install the required libraries:

```bash
pip install pandas seaborn statsmodels matplotlib
```

## How to Run the Project
1. Clone this repository to your local machine.
2. Ensure `marketing_and_sales_data_evaluate_lr.csv` is in the same directory.
3. Open and run all cells inside the `regression_analysis.ipynb` notebook.
